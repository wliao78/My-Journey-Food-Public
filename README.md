# My Journey Food — Public Edition

Independent public-edition source tree for the iPhone food discovery app. This repository does not contain the private edition's Git history, stored reviews, API keys, or personal resources.

Status: release preparation in progress. Do not submit this build to App Store Connect until localization, provider parity, privacy disclosures, screenshots, accessibility, and device testing are complete.

Recommendations are suggestions, not verified menu, opening-hour, or allergy information. Check important details with the venue.
